Blind rating: base vs RL captions

30 held-out COCO test images. Each shows two captions of the same image from Qwen2.5-VL-3B: the base model and the RL model (GRPO with the probe reward, seed 42, step 300), in random order and unlabeled. Pick the caption with fewer errors, and the one you would rather have overall. Which was which is revealed only at the end.

Round 1: both captions at their full length. Round 2 (optional, same images): the base caption is cut at a sentence boundary to the RL caption's length, so neither wins by saying less. Your answers are kept in this browser only; use “Download ratings” at the end to save them.

Keys: 1 2 3 answer the first question (A / same / B), Q W E the second, ← → move.

Images: MS COCO val2014 (Lin et al., 2014); copyright remains with the original Flickr photographers, shown here for research discussion only. Captions: greedy decoding, 512-token budget, prompt “Describe this image in detail.” Images drawn at random (seed 20261024) from the 1,000 coco_v2 rl_test images.
