Qwen2.5-VL: probe-reward GRPO results

The base model, every RL run, and the other hallucination-reduction methods, in one place. Updated 24 Oct 2026.

Old run (L40S)

Fewer hallucinations than the base model even at matched length (−0.38 judged findings per caption), on the old 600-image test set.

New data, two seeds

Fewer findings only because captions got shorter: no change at matched length in any of four checkpoints.

Running now

Two runs that test why: the old probe on the new data (A), and the new probe with a reshaped reward (B). Details.

How to read the tables

Base / RL
Qwen2.5-VL-3B-Instruct without training / after 300 GRPO steps with LoRA, where the only reward is a probe on the model’s own hidden states. Step 300 was fixed as the main checkpoint before training. Greedy captions.
Matched length
Each base caption is cut to its paired RL caption’s token count. Shorter captions contain fewer errors, so this is the fair comparison: a model cannot win just by saying less.
Judged findings
Errors per caption found by the gpt-5.1 judge: wrong objects, attributes, relations and counts. Lower is better.
Judge-free
From the COCO object annotations, no judge. CHAIRS: share of captions naming at least one object not in the image. CHAIRI: share of object mentions that are wrong (precision = 1 − CHAIRI). Recall: share of the image’s annotated objects the caption names.
Δ and CI
RL minus base, paired over images; 95% bootstrap interval underneath. Green: the interval excludes zero and RL is better. Red: it excludes zero and RL is worse.

Reading it

Every new checkpoint has fewer judged findings at full length, and none has fewer at matched length; wrong objects and precision do not improve either. What does reproduce is recall at matched length: in the same number of tokens, the RL model names more of the objects that are really there. The old run improved on all four at matched length.

Caveats on the old row: one seed, and step 250 was chosen after step 300 had failed the matched-length test.

AReward probe = the old run’s probe Did the new probe cause the loss? The new probe’s claim head only looks at about 6% of the caption (the first mention of each COCO object); the old one looks at about 29%.
BSame new probe; reward threshold θ 0.8 plus a risk penalty averaged over the caption A reward chosen offline because it ranks same-length captions better (58.8% vs 52.3% for the reward used above) and does not pay for stopping early.

Seed 42 each, same settings and GPU type as the runs above. Pass rules were written down before training: judged findings and wrong objects both lower at matched length (CI below zero), recall no worse than −1pp.
