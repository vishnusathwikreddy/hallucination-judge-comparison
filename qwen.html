Qwen2.5-VL: probe-reward GRPO results

The base model, every RL run, and the other hallucination-reduction methods, in one place. Updated 24 Oct 2026, afternoon.

Object-probe reward (pmG)

The first run on the new data with fewer hallucinations at matched length: −0.59 judged findings per caption (−29%), the same with a hedge-strict judge, recall unchanged.

Earlier runs on the new data

Published reward (two seeds), old probe (A), risk rate (B) and the old L40S adapter: fewer findings mainly because captions got shorter; no fewer judged findings or wrong objects at matched length.

Running now

pmG with seeds 43 and 44, plus two ablations. One seed so far, so this is not yet a replicated result. Details.

How to read the tables

Base / RL
Qwen2.5-VL-3B-Instruct without training / after 300 GRPO steps with LoRA, where the only reward is a probe on the frozen model’s hidden states. Greedy captions on 1,000 held-out COCO images.
Matched length
Each base caption is cut to its paired RL caption’s token count. Shorter captions contain fewer errors, so this is the fair comparison: a model cannot win just by saying less.
Judged findings
Errors per caption found by the gpt-5.1 judge: wrong objects, attributes, relations and counts. The standard prompt never flags a hedged claim (“appears to be…”) unless the thing is clearly absent; the hedge-strict prompt judges a hedged claim exactly as if it were stated plainly.
CHAIR
Standard CHAIR (Rohrbach et al., the chair.py used by OPERA): COCO segmentation and caption ground truth. CHAIRS: share of captions naming at least one object not in the image. CHAIRI: share of object mentions that are wrong. Recall: share of the image’s objects the caption names. Wrong COCO objects per caption use our synonym matcher on the segmentation labels.
Δ and CI
RL minus base, paired over images; 95% bootstrap interval underneath. Green: the interval excludes zero and RL is better. Red: it excludes zero and RL is worse.

Reading it

pmG is about 12% shorter than the base model, and that alone removes some errors: cutting the base caption to pmG’s length lowers judged findings by 0.24 per caption. pmG removes 0.59 more at the same length, with no loss of recall there. Recall falls only at full length, because the base model’s extra tail names a few more real objects as well as most of its extra errors. The hedge-strict judge finds the same gap, so the gain is not the judge forgiving hedged wording.

Caveats: one seed (43 and 44 are training); pmG was the best of three object-probe configurations evaluated (pmF, pmG, pmH); its shortening comes from the risk term rewarding a safe closing sentence, which a later version should remove.

3. What changed

The probe was not the bottleneck
Against an independent second judge run, the existing hallucination probe already ranks same-length captions of an image at 0.665, next to the judge’s agreement with itself (0.70). Bigger probes, context and other labels did not move it.
The reward shape was
The published reward pays for every object a caption names, so among captions of the same length it prefers the one with more wrong objects (table below).
An object probe
A new head on the same hidden states, trained on COCO ground truth for the groups that first name an object: is this object in the image? AUROC 0.93 on held-out images, against 0.66 for the judge-trained head on the same mentions (0.72 from caption position alone, 0.59 from the object category alone).
Length-matched GRPO
Each sampled caption is scored against the other captions of the same image cut to its own length, so stopping early earns nothing; this is the matched-length evaluation applied inside training.

How each reward ranks pairs of same-length captions of one image (held-out sampled captions; 0.5 = chance), and whether replacing a caption with filler of the same length would pay (src/eval/reward_rank_matched.py):
