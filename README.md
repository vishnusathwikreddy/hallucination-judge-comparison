# Hallucination judge comparison

Static page comparing gpt-5.1, gpt-5.4-mini and gpt-5.4-nano as span-level hallucination judges on
the same 30 COCO captions (five greedy captions from each of six vision-language models). Open
`index.html`, or the GitHub Pages site for this repository.

Images are from MS COCO val2014; copyright remains with the original Flickr photographers.
